# 빛줄기 (Volumetric Light) 효과

`TicketEffect.godRays` — 어두운 무대 위쪽 뒤편에서 따뜻한 빛이 안개와 먼지를 통과해
내려오는 효과. 기존 배경/인물 레이어 구조를 그대로 이용한 **화면 공간 근사**이며
실제 3D 깊이 렌더링은 아니다.

## 렌더링 구조와 깊이 처리

티켓 앞면(`_FrontFace`)은 아래 순서의 Stack이다.

| 순서 | 레이어 | 이 효과가 하는 일 |
| --- | --- | --- |
| 1 | 배경 `DepthPhoto` (`depth_parallax.frag`, 깊이맵) | **원경 안개**: 깊이맵의 먼 픽셀(depth 낮음)에 대비 감소 + 빛 색 안개 (`uHaze`, `uHazeColor`). 깊이맵이 없으면 밴드 폴백 위에 "위쪽 = 원경" 그라데이션 안개 |
| 2 | `EffectLayer(depth: behind)` | `GodRaysPass(behind)`: 원뿔 + 빛줄기 + 산란 매질, 광원 글레어. `ParticlePass.dust(lit: true)`: 원거리 먼지, 빛 원뿔 안에서만 보임 |
| 3 | 인물 `_PersonLayer` (알파 컷아웃 PNG) | 인물이 2번 레이어 위에 그려지므로 **실루엣이 뒤쪽 빛을 자연스럽게 가림**. `PersonRimLight`: 컷아웃 알파를 샘플링해 **광원을 향한 윤곽에만** 림 라이트 (`rim_light.frag`) |
| 4 | `EffectLayer(depth: front)` | `GodRaysPass(front)`: 줄기·글레어 없는 아주 옅은 매질만 (`intensity × frontHaze`). 근거리 먼지 1층 |
| 5 | 비네트, 홀로 포일, 텍스트 | 변경 없음. 빛은 아래로 감쇠해 텍스트 영역에 거의 닿지 않음 |

깊이 정보의 사용:

- **배경 깊이맵(있을 때)** — 원경 안개에 실제 사용. Depth Anything 출력은 "가까움" 값이므로
  `far = 1 - d`로 뒤집어 `smoothstep`으로 안개를 넣는다.
- **인물 알파 마스크** — 실루엣 가림과 림 라이트에 사용. 인물 깊이맵은 사용하지 않는다
  (윤곽 판정에는 알파가 더 정확하다).
- **깊이가 없는 곳** — 레이어 순서(뒤/인물/앞)와 광원 거리 감쇠, 먼지의 3개 패럴랙스 층으로
  근사한다. "먼 곳"은 곧 "광원에 가까운 위쪽"이다.

## 셰이더

- `shaders/god_rays.frag` — 광원 기준 각도로 원뿔을 만들고, 각도 축 1D fBm으로 빛줄기를,
  도메인 워프 fBm으로 천천히 흐르는 매질을 만든다. 시간 계수가 모두 서로 무관한 작은 값
  (0.010~0.030)이라 반복 주기가 눈에 띄지 않고 깜빡임이 없다. `uSection`으로 뒤/앞 모드.
- `shaders/rim_light.frag` — 픽셀 알파 × (광원 방향으로 이동한 샘플의 (1-알파)). 3탭.
  색은 빛 색과 원본 색을 섞어 피부·머리색을 유지한다.
- `shaders/particles.frag` — 기존 먼지 모드에 `uLight*`/`uLightMask`/`uTwinkle`/`uTint` 추가.
  마스크가 0이면 기존 효과와 동일하게 동작한다.
- `shaders/depth_parallax.frag` — `uHaze`/`uHazeColor` 추가. 0이면 기존과 동일.

## 파라미터

`VolumetricLightParams` (`lib/domains/ticket_viewer/effects/volumetric_light.dart`)를
`VolumetricLightController.instance`가 들고 있고, 모든 패스·배경 안개·림 라이트가 paint 시점에 읽는다.

| 필드 | 의미 | 기본값 |
| --- | --- | --- |
| `lightX`, `lightY` | 광원 위치 (카드 비율, y<0 = 위쪽 밖) | 0.64, -0.16 |
| `direction` | 빔 축 기울기 (rad) | -0.10 |
| `spread` | 원뿔 반각 (rad) = 빛줄기 폭 | 0.62 |
| `shaftScale` | 원뿔 내 줄기 개수(세밀도) | 9 |
| `color`, `intensity` | 빛 색·강도 | 따뜻한 텅스텐, 0.72 |
| `reach` | 감쇠 길이 (카드 높이 비율) | 0.95 |
| `fogDensity` | 산란 매질 밀도 | 0.5 |
| `farHaze` | 원경 안개(깊이맵) | 0.42 |
| `frontHaze` | 인물 앞 매질 비율 | 0.26 |
| `dustAmount`, `dustSpeed` | 먼지 양·속도 | 0.7, 0.7 |
| `rimIntensity`, `rimWidth` | 림 세기·두께(px) | 0.55, 3.2 |

기본값은 한눈에 보이는 중간~강한 세기다. 사진에 따라 실험실에서 `intensity`, `fogDensity`,
`frontHaze`를 먼저 조절하면 된다.

## 미리보기 실험실

`VolumetricLab` — 실제 `TicketCard` 렌더러 위에 효과 ON/OFF 스위치, "길게 눌러 원본 비교",
모든 파라미터 슬라이더, 품질 고정(자동/높음/중간/낮음), 모션 감소 토글을 제공한다.

- 진입: 티켓 뷰어 앱바 **빛 조절**(빛줄기 티켓일 때), 제작 화면 효과 선택에서 **빛줄기 미리보기·조절**
  (번들 데모 사진·컷아웃으로 무대를 구성).
- 슬라이더 변경은 컨트롤러만 갱신하고 카드 위젯을 재빌드하지 않는다(페인터가 listen).

## 성능·접근성

- 품질 티어(`EffectSettings`): fBm 옥타브 3/2/2, 먼지 층 3/2/1. **낮음**에서는 인물 앞 매질 패스가
  빠지고 먼지가 꺼진다(기존 `dust`/`smog` 플래그 재사용).
- 모션 감소: OS 설정 또는 실험실 토글 → 정지 프레임(`ViewerConstants.staticEffectTime`).
- 화면에서 사라지면 정지: `PaintWatchdog`가 "틱은 오는데 paint가 호출되지 않는" 상태(스크롤로
  뷰포트 밖, 레이어 분리)를 12틱 후 감지해 Ticker를 멈추고, 다시 paint되는 순간 이어서 재생한다.
  라우트가 덮이면 `TickerMode`가, 앱이 백그라운드면 프레임 스케줄러가 이미 멈춘다.
- 터치/스크롤: 모든 신규 위젯은 `IgnorePointer`, 기존 제스처 경로는 변경 없음.

## 남은 한계

1. **진짜 깊이가 아니다.** 빛줄기는 인물 실루엣 전체에 가려지지만, 인물 옆을 지나는 빛이 인물
   앞·뒤 공기 중 어느 깊이에 있는지는 구분하지 못한다. 앞쪽 매질을 옅게 그려 근사한다.
2. **배경의 물체는 빛을 가리지 않는다.** 배경은 한 장의 사진이라 기둥·조명 리그 뒤에 그림자가
   생기지 않는다. 깊이맵을 이용한 스크린 스페이스 그림자(레이 마칭)는 비용 대비 효과가 작아 넣지 않았다.
3. **림 라이트는 알파 윤곽 기반**이라 인물 내부(코·어깨선 등)의 형태에는 빛이 닿지 않는다.
   컷아웃 경계가 거칠면 림도 거칠어진다(`rimWidth`를 키우면 완화).
4. **광원은 정적**이다. 기울기 패럴랙스는 따라가지만 카드 기울기에 따른 광원 위치 변화는 없다.
5. **깊이맵 없는 티켓**(`contain` 프레이밍, 데모)은 원경 안개가 세로 그라데이션 근사로 대체된다.
6. 실험실에서 조정한 값은 프로세스 메모리에만 남고 티켓에 저장되지 않는다.
